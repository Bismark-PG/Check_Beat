# ♟️ Check Beat
- **A Top-down Rhythm Action Puzzle game where every move must sync with the beat.**

## 🔑 Key Features

- **Procedural Stage Generation**
  + Automatically scales map size, obstacles, and enemy counts with each stage, providing a unique route and infinite replayability.

- **Dynamic Dual-Pattern Enemy AI**
  + Features enemies with two distinct tracking behaviors that pursue the player even when stationary, maintaining constant gameplay tension.

- **Precise Timing Judgment System**
  + Real-time detection of 'Perfect', 'Early', and 'Late' inputs, providing immediate visual feedback to enhance the tactical precision and tactile feel of rhythm actions.

## 🛠️ Development Environment

* **Engine** : Unity 6
* **Language** : C#
* **IDE** : Visual Studio
* **Target Platform:** PC (Windows)
* **Development start date** : 2026.02.25

## 🎮 How To Play

- **Move** : WASD

Check Beat is a rhythm-driven puzzle game where your movement must perfectly match the music.

The game features a procedural generation system that creates new obstacles and enemies every stage.
Theoretically, this allows for infinite gameplay, as the map continues to expand and evolve as long as you survive.

Your inputs are judged in real-time as **Perfect**, **Early**, or **Late**.
For those who find rhythm games challenging, a **Visual Rhythm Indicator** is provided at the bottom of the screen.
Simply press the movement keys when the bars merge in the center to maintain a perfect rhythm and navigate the maze safely.


**Have Fun!**
